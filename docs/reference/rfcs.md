# RFCs

Each design decision of Tack is an RFC in [rfcs/](../../rfcs/), one subject each. An `Active` RFC is in force, and the code conforms to it. When the code and an RFC disagree, the RFC wins, and is amended first. This list is read from the RFCs when the site is built.
